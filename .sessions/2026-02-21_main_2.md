## 关键讨论点

- 将笔记管理页的"类型"筛选从单选 `<select>` 改为自定义多选下拉组件（checkbox 列表），支持同时选择多个笔记类型进行筛选

## 决策记录

- **使用自定义 multi-select 而非原生 `<select multiple>`**：用 div + checkbox 构建自定义多选下拉。理由：原生 `<select multiple>` 的用户体验差，不符合现有 UI 风格
- **trigger 文字显示策略**：0 个选中或全选显示"全部"，1-2 个显示中文名逗号连接，3+ 个显示"已选N项"。理由：在有限按钮宽度内清晰传达选中状态
- **selectedTypes 用 Set 而非数组**：FilterEngine.noteTypes 改为 Set 类型。理由：`has()` 查找性能好，且天然去重
