## 关键讨论点

- YouTube 频道头像无法显示的根因：YouTube RSS (Atom 格式) feed 层级不含 `<icon>` / `<logo>` 标签，`parseFeedXml()` 解析永远拿不到头像
- 方案选定：在 `convertYoutubeUrl()` 已有的 HTML 抓取基础上顺带提取 `og:image` meta 标签作为头像，零额外请求（`@handle` 路径）；对 `/channel/UCxxx` 路径额外 fetch 频道页
- 旧订阅兼容：在 `_fetchAndStoreFeedItems()` 刷新时对无头像的 YouTube feed 自动补取

## 决策记录

- **使用 `og:image` meta 标签提取头像**：YouTube 频道页面的 `og:image` 可靠地包含频道头像 URL。理由：无需 API Key，从已有 HTML 中正则提取即可，兼容性好
- **fallback 策略放在 `_fetchAndStoreFeedItems` 中**：仅在 `!feed.thumbnail && feed.type === 'youtube'` 时触发，取到后写入 storage 不再重复请求。理由：覆盖直接粘贴 RSS URL 添加和旧订阅两种场景
- **`convertYoutubeUrl` 返回值从字符串改为对象 `{ rssUrl, avatar }`**：理由：保持函数职责清晰，调用方可选择性使用 avatar
