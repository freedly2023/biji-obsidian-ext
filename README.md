# 欢迎使用 GET笔记超级助手

订阅更新、视频播客一键提交转录、批量下载导出，支持 Obsidian。

## 功能亮点

- 支持导出为 Markdown、PDF、DOCX。
- 支持 ZIP 下载，或直接写入 Obsidian Vault。
- 支持命名模板、Frontmatter 字段与标签策略。
- 支持“仅导出新增笔记”，减少重复导出。
- 支持订阅源管理、定时检查与批量提交。
- 支持 YouTube、B 站、小宇宙页面注入按钮。

## 核心卖点

### 一键收内容

YouTube、B站、小宇宙页面可直接提交，不用手动复制链接。

### 自动追更新

订阅后自动检查新内容，支持批量提交，省去重复操作。

### 批量下载导出到 Obsidian

支持 Markdown、PDF、DOCX，可 ZIP 下载，也可直接写入 Vault。

## 安装方式（开发者模式）

1. 打开浏览器扩展管理页（如 `chrome://extensions/`）。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目根目录：`biji-obsidian-ext`

## 快速上手

1. 安装扩展后，先打开并登录 biji.com。
2. 在插件弹窗点击“获取全部笔记”。
3. 选择导出格式与导出方式。
4. 点击“导出全部笔记”或“仅导出新增笔记”。
5. 如需长期自动采集内容，在“设置”中配置订阅源与自动检查。

## 页面说明

- 弹窗：抓取、导出、增量导出、订阅快速处理
- 设置页：命名模板、分类规则、导出偏好、性能参数、订阅参数
- 笔记管理页：搜索、筛选、分页、批量导出
- 订阅管理页：订阅源维护、条目筛选、批量提交

## 权限说明

- `storage`：保存设置、笔记缓存、导出记录
- `cookies`：辅助访问登录态相关请求
- `alarms`：执行订阅源定时检查
- 站点权限：用于读取目标页面内容并提交到 Get 笔记接口

## 隐私说明

- 插件数据默认保存在浏览器本地存储中。
- 不会将你的 Obsidian 本地文件主动上传到第三方服务器。
- 只有你主动触发抓取、导出、提交时才会发起相应网络请求。
